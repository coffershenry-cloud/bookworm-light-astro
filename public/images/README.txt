This folder contains all 79 non-JSON files exported under Takeout/Blogger/Albums/InkGlobe/, retaining their original filenames, plus the 80 JSON metadata sidecars from that album. The Blogger XML image references are inventoried in ../metadata/image-references.csv and .json. The Takeout album is a general album export; a one-to-one mapping between each image URL in post HTML and a specific album file is not guaranteed by the source data. External image URL reachability has not been tested.
